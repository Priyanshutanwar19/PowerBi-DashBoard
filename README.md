# Air Quality Index (AQI) Analytics Dashboard

## 📌 Project Overview
The **Air Quality Index (AQI) Analytics Dashboard** is an interactive Power BI project designed to analyse air quality data across multiple cities. It provides insights into pollution levels, pollutant trends, and regions with high air pollution using interactive visualizations and key performance indicators (KPIs).

The project uses Microsoft Excel for data cleaning and transformation and Power BI for data modelling and visualization.

## 🎯 Objectives
- Analyse AQI data across multiple cities.
- Monitor major air pollutants, including PM2.5, PM10, NO2, and SO2.
- Identify regions with high pollution levels.
- Explore seasonal pollution patterns and pollutant trends.
- Present insights through interactive charts, KPIs, and filters.

## ✨ Key Features
- **Interactive Dashboard:** Explore air quality data through dynamic visuals and filters.
- **Pollutant Analysis:** Track PM2.5, PM10, NO2, and SO2 concentrations.
- **KPI Monitoring:** Understand key air quality indicators at a glance.
- **City-wise Analysis:** Compare pollution levels across different cities.
- **Trend Analysis:** Identify pollution patterns and changes over time.
- **High-Risk Region Identification:** Highlight areas experiencing elevated pollution levels.

## 🛠️ Tech Stack
- **Power BI** – Dashboard development, data modelling, and visualization.
- **Microsoft Excel** – Data cleaning, preprocessing, and transformation.

## ⚙️ Project Workflow
1. **Data Collection:** Obtained the AQI dataset for analysis.
2. **Data Cleaning:** Handled data inconsistencies and prepared the dataset using Microsoft Excel.
3. **Data Transformation:** Organized the data into a suitable format for analysis.
4. **Data Modelling:** Structured the data in Power BI for effective analysis.
5. **Dashboard Development:** Created interactive visuals, KPIs, charts, and filters.
6. **Insights Generation:** Analysed pollutant levels, city-wise differences, and seasonal trends.

## 📊 Insights
The dashboard helps users:
- Compare air pollution levels across cities.
- Understand the contribution and trends of major pollutants.
- Identify locations with elevated pollution levels.
- Explore changes in air quality over time.
- Support data-driven awareness of environmental conditions.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `.pbix` dashboard file in Power BI Desktop.
4. If required, update the dataset source path.
5. Refresh the data to load the latest available dataset.
6. Use the dashboard filters and visualizations to explore the results.
